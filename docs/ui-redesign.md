# UI 重设计规格（像素风 · Claude 配色）

2026-10 与用户逐项确认。原创像素外壳，致敬 Minecraft 的方块质感，但不使用 Mojang 任何贴图、字体、音效，也不加入游戏元素（快捷栏、经验条、成就等）。

## 配色

| 角色 | 浅色 | 深色 | 米色护眼 |
|---|---|---|---|
| 背景 | `#FAF9F5` | `#141413` | `#F1E7D0` |
| 方块面板 | `#E8E6DC` | `#262624` | `#E6D8B8` |
| 面板亮边 / 暗边 | 白 / `#B0AEA5` | `#3A3936` / `#0B0B0A` | `#F8F0DC` / `#BFA77C` |
| 描边 | `#141413` | `#000000` | `#3B2F20` |
| 正文 | `#141413` | `#FAF9F5` | `#3B2F20` |
| 次要文字 | `#6B6A64` | `#B0AEA5` | `#7A6748` |

强调色在三套主题里通用：陶土橙 `#D97757`（主按钮、进度），蓝 `#6A9BCC`，苔绿 `#788C5D`（完成状态），中灰 `#B0AEA5`。错误色为 `#B5462F`。

主题默认跟随系统的深浅色，设置页可以手动选择：跟随系统、浅色、深色、米色。

## 字体

- 像素字体：Fusion Pixel 12px proportional zh_hans（OFL），用于标题、按钮、标签和数字，中英文都用。
- 英文正文：Lora（OFL），统一使用 `ReadingEnglish`（18sp / 29sp）；被讲解的完整表达用同一字号加粗。
- 中文正文、讲解：Noto Serif SC Regular（思源宋体，OFL），统一使用 `bodyLarge`（17sp / 28sp）。
- 全部打包进 APK，APK 大约增加 19MB。

## 方块与质感

- 1 个美术像素 = 2dp。
- 方块的边角做 1 个美术像素的切角，不使用圆角。
- 面板：1 个美术像素宽的深色描边，内侧左上是亮边、右下是暗边（立体斜面），填充色带有确定性的细微像素噪点纹理。
- 纹理只用在顶栏、按钮和卡片上。页面背景和正文区保持纯色。
- 按钮按下时斜面反转，内容下移 1 个美术像素。
- 图标全部是原创的 16×16 像素图标，用字符网格定义。
- 尽量少用动效。唯一的特色动效是下载进度的“挖方块”：方块随进度出现裂纹。

## 页面

- 教材库：像素顶栏，包含标题和齿轮（进入设置），下面是更新卡片与单列教材卡片。通过下拉手势刷新目录，空列表同样支持；刷新期间只显示顶部指示器，重复手势不重启请求。已下载课程只显示绿色对勾，有更新时显示标签，未下载不显示标签。下载有百分比时显示挖方块与进度文字；未知进度时显示分段等待条，避免两种图形进度同时出现。移除本地目录导入、授权与扫描，云端已下载但不在当前目录中的教材保留在“离线课程”分区。
- 学习页：视频占 25%，文本占 75%（横屏时左右排列），不做句子高亮。英文用 Lora，中文用思源宋体。讲解按钮做成像素小按钮。详情顶栏内容 32dp（不含系统状态栏），返回按钮 24dp、图标 14dp，标题 16/20sp；播放控制栏 26dp，按钮 22dp、图标 12dp，时间 10/14sp，进度区域 14dp。手势提示 11/14sp、上下各 2dp，无强制换行，放大字体时允许自然换行。
- 讲解：保留底部弹层和原文预览卡片。小节标题用较大的像素字体，表达和说明通过间距分组，不加彩色左竖条、小方块或彩色正文。易错点使用编号。
- 设置：纯色平面展示主题选择、检查更新、版本号，小节用分隔线区分。版本号只在设置页显示。
- 常用布局间距使用 4/8/16/24dp：表达与说明 4dp，标题与内容 8dp，小节与卡片之间 16–24dp；按钮保留斜面反馈，移除文字阴影。
- 应用图标：像素风格，陶土橙的方块上画一个播放符号。

## 后台与锁屏播放

ExoPlayer 移到 Media3 的 `MediaSessionService`（`playback/PlaybackService`），以前台服务形式运行，并提供媒体通知和锁屏控制。学习页通过 `MediaController` 连接这个服务。锁屏或切到后台时不再暂停，播放进度由服务定期保存。离开学习页时停止播放并清空媒体。
